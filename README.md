# 🧠 Deep Learning Laboratory

This repository contains the laboratory work, assignments, and case studies completed during my Deep Learning course. The experiments were designed to provide practical exposure to modern deep learning techniques, covering both theoretical concepts and hands-on implementation using Python and TensorFlow/Keras.

Throughout these labs, I explored the complete deep learning workflow—from data preprocessing and model building to training, evaluation, and performance analysis across both Computer Vision and Natural Language Processing tasks.

---

## Objectives

The primary objectives of these laboratory exercises were to:

- Understand the fundamentals of Deep Learning.
- Implement neural networks for real-world problems.
- Explore different deep learning architectures.
- Learn model training, evaluation, and optimization techniques.
- Gain practical experience with popular deep learning frameworks.

---

## Laboratory Work

The repository includes experiments and case studies on topics such as:

- Multi-Layer Perceptron (MLP) implementation from scratch using NumPy
- Convolutional Neural Networks (CNN)
- CNN Regularization using Dropout
- MNIST Digit Recognition
- CIFAR-10 Image Classification
- Brain Tumor Detection using Deep Learning
- IMDB Sentiment Analysis
- Sequence-to-Sequence (Seq2Seq) Models
- Attention Mechanism
- BERT for Natural Language Processing
- Additional Deep Learning laboratory assignments and experiments
